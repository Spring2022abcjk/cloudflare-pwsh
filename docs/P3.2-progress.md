## Scope and Acceptance Gates

The first P3.2 representative cmdlets are:

- `Get-CfZone`
- `Get-CfDnsRecord`
- `New-CfDnsRecord`
- `Remove-CfDnsRecord`

Generated PSCmdlets must convert bound PowerShell parameters into runtime
arguments and execute through `GeneratedOperationMetadataAdapter` and the
shared dispatcher. They must not duplicate HTTP construction, serialization,
response parsing, retry, pagination, cancellation, or error mapping.

Acceptance evidence must cover parameter-set and metadata parity with the
projection artifact, actual pipeline binding, typed output, shared-runtime
pagination, `ShouldProcess`/`-WhatIf`, `Optional<T>` presence/null semantics,
stable generated/handwritten error parity, and captured behavioral parity for
method, path, query, headers, body, retries, paging, outputs, and errors.

If and only if the four representative cmdlets reach full parity, add
`Set-CfDnsRecord` as the final P3.2 multi-operation PUT/PATCH validation.
