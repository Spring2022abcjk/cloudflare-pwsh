# P3.1 Production Runtime Progress

## Implemented

- Added transport-neutral `CloudflareRequest` and `CloudflareResponse` contracts.
- Added `ICloudflareTransport` and an `HttpClientTransport` adapter using
  `ResponseHeadersRead`.
- Added `RuntimeOperationMetadata`, bound parameters, request/response
  representation metadata, and explicit multipart-part metadata.
- Added API Token `AuthenticationContext` support without putting credentials in
  generated metadata.
- Added serializer selection for JSON and `multipart/form-data`.
- Added an injectable `ICloudflareResponseParser` contract with JSON, raw text,
  binary-stream, and no-content parsers.
- Added generic `CloudflareRuntimeDispatcher.ExecuteAsync<T>` for path, query,
  header, request-body, response-representation, envelope, and error dispatch.
- Added raw text parsing and a response-owned binary `Stream` wrapper.
- Added a replayability signal to request content factories; caller-owned
  multipart streams are kept open and conservatively marked non-replayable until
  a fresh-stream factory exists.
- Added shared pagination strategy execution for `SinglePage`,
  `V4PagePaginationArray`, `V4PagePagination`, `CursorPagination`,
  `CursorPaginationAfter`, and `CursorLimitPagination`, including repeated
  cursor protection and cancellation propagation.
- Added the default max-two retry policy with connection/timeout, 408/409/429,
  5xx, `x-should-retry`, `Retry-After`, `retry-after-ms`, exponential backoff,
  and jitter support.
- Added explicit idempotency metadata and key injection. Mutation retry is
  disabled by default; it requires a supplied key and an operation declaration
  that marks the request retry-safe. Automatic key generation is rejected until
  a product policy exists.
- Migrated all handwritten DNS operations (`List`, `Get`, `Create`, `Update`,
  `Edit`, and `Delete`) through the generic dispatcher while preserving their
  public client signatures and effective DELETE-without-body behavior.
- Added a normalized-response pagination adapter that reads result and page-info
  paths from explicit `RuntimePaginationMetadata` bindings, including nested
  item and cursor representations, while retaining `ResponseFields` as evidence.
- Extended `CloudflareApiException` with retry count and request-ID lookup, and
  mapped parser/transport construction failures into the same stable exception
  path.
- Added generated declarative runtime-operation metadata and a generic adapter
  that maps generated method/path, path/query/header parameters, request and
  response representations, multipart parts, and pagination bindings into the
  shared dispatcher contracts. The handwritten DNS client now looks up all six
  operations from generated metadata; it does not own transport definitions.
- Added the P3.1 runtime direction and acceptance gate to the project docs.

## Acceptance Evidence

P3.1 acceptance status: complete. All ten gates have deterministic mock,
static, host, or regression evidence as appropriate; real-account behavior is
not used to close a mock gate.

1. Generic dispatch executes generated metadata: `generated metadata adapter
   contract` passed and the six handwritten DNS operations now dispatch through
   `CfDnsRecordRuntimeMetadata`.
2. Existing JSON Cloudflare-result behavior: C# runtime tests and ModuleSmoke
   passed, including DNS list/get/create/update/edit/delete.
3. Raw text and binary mock operations: `raw text dispatcher` and `binary
   dispatcher and stream ownership` passed.
4. Multipart construction: `multipart dispatcher` and the generated multipart
   adapter contract passed for text/binary parts and no-content response.
5. Recognized pagination: `SinglePage`, `V4PagePaginationArray`,
   `V4PagePagination`, `CursorPagination`, `CursorPaginationAfter`, and
   `CursorLimitPagination` are implemented and covered by `pagination
   strategies`; normalized response-field mapping is also covered.
6. Retry/replayability: `retry policy and headers`, `non-replayable request is
   not retried`, and mutation idempotency-boundary tests passed.
7. API Token context: generated JSON dispatch and ModuleSmoke verified the
   `Authorization: Bearer` header.
8. Stable diagnostics: C# error tests and ModuleSmoke verified stable
   ErrorRecord ID/category/target plus request ID, Cloudflare code, raw body,
   and preserved inner transport exception behavior.
9. Generated metadata transport neutrality: generator output is declarative
   `GeneratedOperationMetadata`; adapter/source inspection found no operation-id
   transport branch, and the generated metadata contract passed.
10. P1/P2 regression and documentation: `Invoke-P24Tests.ps1` passed the full
    P1→P2.4 chain, including golden snapshots and compatibility reports; this
    progress document and `docs/architecture.md` record the final boundary.

## Still Deferred

- Idempotency policy and mutation safety remain unresolved.
- Automatic idempotency-key generation and operation-specific Cloudflare
  idempotency documentation remain deferred.
- Legacy authentication, full PowerShell binary UX (`OutFile`/`PassThru`),
  full DNS real-account behavior, and HTTP `2xx` with `success=false` semantics
  remain unresolved.
- P3.2 generated public `PSCmdlet` migration and publishing/release work remain
  outside this gate.
