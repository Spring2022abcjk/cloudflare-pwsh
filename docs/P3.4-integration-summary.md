## Not release-ready

The integrated P3.3/P3.4 result is a completed release-engineering foundation,
not a published or production-accepted release. The following remain outside
this closure:

- real-account acceptance and constrained live Cloudflare behavior;
- device/manual UX and complete help quality review;
- broader explicit public admission and full generated-cmdlet migration;
- Gallery publishing and release/security policy evidence;
- legacy authentication decisions;
- automatic idempotency and complete mutation retry policy;
- full binary PowerShell UX; and
- the unresolved HTTP `2xx` with `success=false` semantic.

The next release phase must preserve the distinction between local/mock,
host, package, remote-CI, real-account, device/manual, publishing, and release
evidence.
