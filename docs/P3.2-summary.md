# P3.2 Summary — Generated Public PowerShell Surface

## Scope and decision

P3.2 validated a generated public `PSCmdlet` surface on branch `P3.2` for
`Get-CfZone`, `Get-CfDnsRecord`, `New-CfDnsRecord`,
`Remove-CfDnsRecord`, and the conditional `Set-CfDnsRecord` PUT/PATCH slice.

The evidence supports using generated cmdlets as the maintained surface for
these validated operations. The module still exports handwritten functions
alongside the generated commands during transition; handwritten DNS functions
remain the command-resolution reference until broader migration evidence and
release gates exist. This is not a release-ready SDK decision.

## Evidence

- `tools/Generate-P32Source.ps1` reproduces the generated source from
  `tools/templates/P32RepresentativeCmdlets.cs.tmpl`; repeated generation
  produced identical source SHA-256 output.
- Generated source contains only projection parameter binding,
  `ShouldProcess`, generated metadata selection, and shared base calls. Static
  checks reject transport, serialization, parsing, retry, paging-loop,
  cancellation, and error-mapping logic.
- Deterministic mock parity covers method, path, query, Authorization/content
  headers, request body, typed or empty output, paging, ErrorRecord fields,
  WhatIf no-request behavior, requiredness, and applicability.
- `Set-CfDnsRecord` passed both `PUT`/`Replace` and `PATCH`/`Edit` parity,
  including body, output, WhatIf, and ErrorRecord behavior.
- Final `tools/Invoke-P32Tests.ps1` passed Release build with zero warnings and
  zero errors, P32Smoke, C# runtime `PASS total=18`, module smoke, and the full
  P1–P2.4/P3.1 regression chain. `git diff --check` passed.

## Boundaries

Mock evidence is not real-account evidence. No complete real-account DNS
behavior or release/publishing validation is claimed. The shared runtime is a
production runtime foundation, not release-ready by itself.

## Deferred

- Legacy authentication.
- Automatic `Idempotency-Key` generation.
- Complete mutation retry safety.
- HTTP `2xx` with `success=false` semantics.
- Full binary PowerShell UX.
- Complete real-account behavior.
- Publishing, packaging, and release work.
