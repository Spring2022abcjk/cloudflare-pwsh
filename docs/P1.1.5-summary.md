# P1.1.5 Generalized Vertical Slice Summary

长期架构边界与后续原则见 [architecture](./architecture.md)、[roadmap](./roadmap.md) 和 [development principles](./development-principles.md)。

## Fixed Prototype Debt

- Replaced the YAML indentation/regex parser with order-independent JSON configuration: `overrides/api-corrections.json` and `overrides/powershell-projection.json`.
- Replaced the generator's endpoint-specific DELETE correction with a generic correction pipeline supporting operation id, method/path, schema name, and resource path matching. Every applied rule is retained in `correctionTrace`.
- Added correction actions for request body, parameters, responses, pagination, and operation semantics.
- Removed DNS operation-id switches from symbol generation. Symbols are derived from resource path, semantic kind, and operation id with stable sanitization, keyword handling, numeric-prefix handling, and collision suffixes.
- Fixed multi-operation projection: public parameters are a union with `AppliesTo`/`RequiredIn`; every parameter set owns an `OperationBinding` with method, path, path/query bindings, and body model.
- Replaced string ordering for `ConfirmImpact` with an explicit `None < Low < Medium < High` rank; the synthetic regression proves Low + High → High.
- Added `Optional<T>` with omitted, explicit-null, and specified-value states.
- Replaced the broad DNS body prototype with typed `CfARecordInput`, `CfMxRecordInput`, `CfCaaRecordInput`, `CfHttpsRecordInput`, and `CfSvcbRecordInput` variants.

## Architecture Decisions

- Generated C# remains route A: model and projection metadata only. It is under `Generated/Models` and `Generated/Metadata`.
- The ergonomic PowerShell surface remains handwritten in `module/Cloudflare.PowerShell/Cloudflare.PowerShell.psm1`.
- The generator consumes corrected normalized JSON plus projection JSON only. It never reads raw OpenAPI.
- Projection regression runs the same generator against P1.2 normalized DNS output; golden output remains stable.
- JSON is the configuration format for this stage because it provides structural parsing, stable schema validation hooks, and direct C# compatibility.

## Remaining Deferred Work

- JSON Schema validation for the configuration documents is reserved for a later quality pass; the parser itself is now structural and order-independent.
- Full typed variants for every DNS record remain deferred; five representative variants are generated and tested.
- Generated PowerShell cmdlet classes, full help, retry/idempotency, multipart/binary runtime, and module publishing remain deferred.

## Breaking Changes from P1.1

- Override files changed from YAML to JSON.
- Generated source moved from `Generated/Cmdlets` and flat metadata files to `Generated/Models` and `Generated/Metadata`.
- Golden file names now identify projection metadata rather than pretending to be generated cmdlet classes.
- `New-CfDnsRecord -Record` now requires a typed `CfDnsRecordInput` variant; `Set-CfDnsRecord` retains hashtable prototype input for its Replace/Edit experiment.
- The projection artifact now contains parameter applicability, parameter sets, and operation bindings instead of copying the first operation's parameters.
