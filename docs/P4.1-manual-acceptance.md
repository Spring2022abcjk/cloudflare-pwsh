## Command-by-command acceptance

### Get-CfZone

Pass. `Get-Help`, `Get-Help -Full`, `Get-Command -Syntax`, List/Get parameter
sets, two examples, typed `CfZone` output, and `ZoneId` help were populated in
the candidate. `CfZone.Id` exposes the ETS `ZoneId` alias, and:

    $zone | Get-CfDnsRecord

bound the zone identity successfully through the local mock handler.

### Get-CfDnsRecord

Pass. List/Get syntax, `ZoneId`, `DnsRecordId`, the `RecordId` parameter alias,
filters, pagination, typed `CfDnsRecord` output, and four examples were
present. List, get, filter, paging, and explicit-scope pipeline workflows
passed:

    $record | Get-CfDnsRecord -ZoneId $zone.ZoneId

The record object supplies only record identity; it does not supply parent
scope.

### New-CfDnsRecord

Pass. Candidate help names `CfDnsRecordInput`, `CfARecordInput`,
`CfMxRecordInput`, `CfCaaRecordInput`, `CfHttpsRecordInput`, and
`CfSvcbRecordInput`, documents `IncludeShadowMetadata`, and contains two
parser-valid examples. A typed `CfARecordInput` was constructed with
presence-aware fields. `-WhatIf` emitted ShouldProcess output and made no mock
HTTP request. No real mutation was attempted.

### Set-CfDnsRecord

Pass with explicit scope. The candidate documents both parameter sets and the
PATCH-style Edit versus PUT/complete Replace distinction. Typed
`DnsRecordId`/`RecordId` property binding, hashtable bodies,
`IncludeShadowMetadata`, high-impact ShouldProcess, and `-WhatIf` were
verified:

    $record | Set-CfDnsRecord -ZoneId $zone.ZoneId -Edit @{ content = '198.51.100.5' }

The corresponding no-scope invocation failed with
`InputObjectMissingMandatory` for `ZoneId` before dispatch. The module does
not infer scope from the record.

### Remove-CfDnsRecord

Pass with explicit scope. Help documents `DnsRecordId`/`RecordId`, high
`ConfirmImpact`, `-WhatIf`, and no success output. The explicit-scope pipeline
WhatIf performed no mock request and the normal mock DELETE returned no object:

    $record | Remove-CfDnsRecord -ZoneId $zone.ZoneId -WhatIf

The no-scope pipeline invocation failed with `InputObjectMissingMandatory` for
`ZoneId` before dispatch. This is intentional and is not an implicit parent
scope feature.
