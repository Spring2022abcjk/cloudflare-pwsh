# P3.1 Production Runtime Progress

## Implemented

- Added transport-neutral `CloudflareRequest` and `CloudflareResponse` contracts.
- Added `ICloudflareTransport` and an `HttpClientTransport` adapter using
  `ResponseHeadersRead`.
- Added `RuntimeOperationMetadata`, bound parameters, request/response
  representation metadata, and explicit multipart-part metadata.
- Added API Token `AuthenticationContext` support without putting credentials in
  generated metadata.
- Added serializer selection for JSON and `multipart/form-data`.
- Added an injectable `ICloudflareResponseParser` contract with JSON, raw text,
  binary-stream, and no-content parsers.
- Added generic `CloudflareRuntimeDispatcher.ExecuteAsync<T>` for path, query,
  header, request-body, response-representation, envelope, and error dispatch.
- Added raw text parsing and a response-owned binary `Stream` wrapper.
- Added a replayability signal to request content factories; caller-owned
  multipart streams are kept open and conservatively marked non-replayable until
  a fresh-stream factory exists.
- Added shared pagination strategy execution for `SinglePage`,
  `V4PagePaginationArray`, `V4PagePagination`, `CursorPagination`,
  `CursorPaginationAfter`, and `CursorLimitPagination`, including repeated
  cursor protection and cancellation propagation.
- Added the default max-two retry policy with connection/timeout, 408/409/429,
  5xx, `x-should-retry`, `Retry-After`, `retry-after-ms`, exponential backoff,
  and jitter support.
- Added explicit idempotency metadata and key injection. Mutation retry is
  disabled by default; it requires a supplied key and an operation declaration
  that marks the request retry-safe. Automatic key generation is rejected until
  a product policy exists.
- Migrated all handwritten DNS operations (`List`, `Get`, `Create`, `Update`,
  `Edit`, and `Delete`) through the generic dispatcher while preserving their
  public client signatures and effective DELETE-without-body behavior.
- Added a normalized-response pagination adapter that reads result and page-info
  paths from explicit `RuntimePaginationMetadata` bindings, including nested
  item and cursor representations, while retaining `ResponseFields` as evidence.
- Extended `CloudflareApiException` with retry count and request-ID lookup, and
  mapped parser/transport construction failures into the same stable exception
  path.
- Added the P3.1 runtime direction and acceptance gate to the project docs.

- `pwsh -NoLogo -NoProfile -File .\tools\Invoke-P31RealAccountValidation.ps1`:
  read-only live check passed API Token verification and zone listing

- `pwsh -NoLogo -NoProfile -File .\tools\Invoke-P24Tests.ps1`: passed the full
  P1/P2.1/P2.2/P2.3/P2.4 chain, including solution build, module smoke, golden
  snapshots, and real normalized API/projection compatibility reports.
- New mock coverage verifies:
  - JSON `CloudflareResult` envelope dispatch and API Token header;
  - raw `text/plain` response parsing;
  - binary stream parsing and response lifetime through stream disposal;
  - multipart text/binary parts, content types, and no-content response.
  - all six shared pagination strategies, empty-page/total-page termination,
    repeated-cursor protection, nested after-cursor extraction, cancellation,
    and later-page failure propagation;
  - retry sequence 500 → 429 → 200, `retry-after-ms`, and no retry for a
    non-replayable stream body;

    explicit idempotency key;

    list/get/create/update/edit/delete through the same generic runtime;
  - caller-owned multipart stream lifetime and conservative replayability.

## Still Deferred

- Idempotency policy and mutation safety remain unresolved.
- Automatic idempotency-key generation and operation-specific Cloudflare
  idempotency documentation remain deferred.
- Generated-operation adapters still need broader coverage beyond the generic
  runtime metadata and normalized response adapter contract.
- Legacy authentication, full PowerShell binary UX, full DNS real-account
  validation, and HTTP `2xx` with `success=false` semantics remain unresolved.

## Next

3. Keep idempotency policy, legacy authentication, full PowerShell binary UX, and
