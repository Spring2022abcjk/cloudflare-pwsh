## Projection conflict reduction and admission policy

The bounded projection-reduction follow-on uses the global baseline as an
immutable before report at `artifacts/coverage/before-global-coverage.json` and
regenerates the after report at `artifacts/coverage/after-global-coverage.json`.
The deterministic taxonomy is recorded in
`artifacts/coverage/blocker-taxonomy.{json,md}`.

The shared builder resolves two general projection categories without
resource-specific branches: 458 rows through normalized scope-key
disambiguation and 53 rows through normalized HTTP-method disambiguation. The
remaining 57 projection conflicts are same-scope/same-method parameter-set
ambiguities and remain `UnsupportedProjectionCapability` for 53 rows and
`NeedsManualReview` for four low-confidence rows. The final global delta is:

| Measure | Before | After |
| --- | ---: | ---: |
| Projection-ready stage operations | 2,839 | 3,350 |
| Projection conflicts | 568 | 57 |
| `UnsupportedProjectionCapability` | 491 | 53 |
| `NeedsManualReview` | 617 | 617 |
| Current public operations | 8 | 8 |

The 617 low-confidence semantic rows remain manual; 77 of them overlapped the
before projection-conflict population. The new
`overrides/public-admission-policy.json` is explicit-only: deterministic
projection is necessary but does not admit a public cmdlet. Typed models,
runtime capability, compatibility visibility, naming/safety decisions,
mock/source parity, and bounded policy admission remain independent gates.

The reviewer-blocking admission mismatch is repaired with Option B: D1/D2
remain bounded validation slices and are no longer formal module exports. The
canonical admitted surface is the five-cmdlet P3.2 model. The production
acceptance gate `tools/Invoke-P33AdmissionParity.ps1` compares that surface by
canonical identity with coverage, P2.4 compatibility, generated public source,
the manifest, module runtime exports, and generated help; extra and missing
commands fail. The shared PowerShell name canonicalizer is used by projection
and compatibility collision validation; generated source consumes the canonical
artifact instead of inventing another public-name rule. Scope resolution is
rejected when final cmdlet-plus-parameter-set identities collide. See
`docs/P3.3-projection-reduction-summary.md` for the focused repair record.
