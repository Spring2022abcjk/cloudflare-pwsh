# P3.2 Generated Public PowerShell Surface Progress

P3.2 implementation and acceptance evidence are complete on branch `P3.2`,
based on the completed P3.1 runtime foundation. This document records the
phase boundary, evidence, deferred work, and next actions. The final
`P3.2-summary.md` and generated-versus-handwritten ADR were created only after
their evidence existed.

## Implemented

- P3.1 was fast-forward merged into `main` at `ed00f13`.
- The `P3.2` task branch was created from that merged commit; the source
  `P3.1` branch remains preserved.
- A shared `CloudflareCmdletBase` now owns PowerShell host concerns only:
  runtime construction, cancellation, common bound-parameter conversion,
  output writing, and stable `CloudflareApiException` to `ErrorRecord`
  conversion.
- Generated public command metadata and runtime metadata cover the first four
  representative commands: `Get-CfZone`, `Get-CfDnsRecord`,
  `New-CfDnsRecord`, and `Remove-CfDnsRecord`.
- The conditional `Set-CfDnsRecord` slice is now implemented for both `PUT`
  (`Replace`) and `PATCH` (`Edit`) after the four-command parity gate passed.
- The module exports the generated cmdlets alongside the handwritten baseline
  while parity evidence is being collected. The handwritten functions remain
  the normal command-resolution reference during this transition.
- `Optional<T>.ExplicitNull` and generated DNS input serialization preserve
  omitted versus explicit-null fields.
- Generated cmdlet source is reproduced from
  `tools/templates/P32RepresentativeCmdlets.cs.tmpl` by
  `tools/Generate-P32Source.ps1`; the generator rejects transport, body/query
  serialization, response parsing, retry, paging-loop, cancellation, and
  error-mapping logic in the generated source.
- Shared `CloudflareCmdletBase` owns generated invocation error conversion and
  pagination enumeration; generated commands remain projection/runtime-call
  adapters.
- The shared runtime is a production runtime foundation for these generated
  operations; it is not release-ready by itself.

## Scope and Acceptance Gates

The first P3.2 representative cmdlets are:

- `Get-CfZone`
- `Get-CfDnsRecord`
- `New-CfDnsRecord`
- `Remove-CfDnsRecord`

Generated PSCmdlets must convert bound PowerShell parameters into runtime
arguments and execute through `GeneratedOperationMetadataAdapter` and the
shared dispatcher. They must not duplicate HTTP construction, serialization,
response parsing, retry, pagination, cancellation, or error mapping.

Acceptance evidence must cover parameter-set and metadata parity with the
projection artifact, actual pipeline binding, typed output, shared-runtime
pagination, `ShouldProcess`/`-WhatIf`, `Optional<T>` presence/null semantics,
stable generated/handwritten error parity, and captured behavioral parity for
method, path, query, headers, body, retries, paging, outputs, and errors.

If and only if the four representative cmdlets reach full parity, add
`Set-CfDnsRecord` as the final P3.2 multi-operation PUT/PATCH validation.

- Complete real-account behavior.

- Final generated-versus-handwritten public-surface decision until parity,
  testability, generator complexity, loading, metadata quality, UX, and
  maintenance evidence is available.
